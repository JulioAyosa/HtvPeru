FASE 2: Configurar el archivo .env en el Servidor

⚠️ IMPORTANTEste es el paso más crítico. El .env controla las credenciales de la base de datos, el entorno y la seguridad de los Cron Jobs.

Crear el archivo .env en la raíz del proyecto dentro de public_html/:

# ==========================================
# CONFIGURACIÓN DE BASE DE DATOS
# ==========================================
# Estos datos los encuentras en cPanel > MySQL Databases
DB_HOST=localhost
DB_NAME=tucuenta_htvperu
DB_USER=tucuenta_dbuser
DB_PASS=TuContraseñaSuperSegura123!
DB_CHARSET=utf8mb4

# ==========================================
# ENTORNO DE APLICACIÓN
# ==========================================
APP_ENV=production
APP_DEBUG=false
APP_URL=https://htvperu.com.pe

# ==========================================
# SEGURIDAD Y TAREAS (CRON)
# ==========================================
# Generar un token único en Terminal SSH:
#   php -r "echo bin2hex(random_bytes(32));"
CRON_TOKEN=PEGAR_AQUI_EL_TOKEN_GENERADO

¿Cómo crear la Base de Datos en cPanel?

  1. Ir a cPanel → MySQL® Databases
  2. Crear una nueva base de datos (ejemplo: tucuenta_htvperu)
  3. Crear un nuevo usuario con contraseña fuerte
  4. Asociar el usuario a la base de datos con TODOS LOS PRIVILEGIOS
  5. Ir a cPanel → phpMyAdmin, seleccionar tu nueva BD
  6. Click en Importar → subir el archivo database.sql de tu proyecto local
  7. Verificar que todas las tablas se crearon correctamente (deben ser ~14 tablas)
⚠️ WARNINGEl nombre de la BD en cPanel siempre lleva el prefijo de tu cuenta. Ejemplo: si tu cuenta es htvperu, la BD será htvperu_nombrebd. ¡Usa ese nombre completo en el .env!

FASE 3: Modificar el .htaccess para Producción

El .htaccess actual tiene rutas hardcodeadas a /piura_noticias_php/. En producción debes limpiar esas referencias.

3.1 Cambiar el ErrorDocument (línea 6)

- ErrorDocument 404 /piura_noticias_php/404.php+ ErrorDocument 404 /404.php

3.2 Cambiar las reglas del Front Controller (líneas 124-131)

  # Evitar bucles redirigiendo peticiones ya apuntando a public/- RewriteCond %{REQUEST_URI} !^/piura_noticias_php/public/+ RewriteCond %{REQUEST_URI} !^/public/   # Excluir recursos estáticos- RewriteCond %{REQUEST_URI} !^/piura_noticias_php/(css|js|img|uploads|dist) [NC]+ RewriteCond %{REQUEST_URI} !^/(css|js|img|uploads|dist) [NC]   # Enviar todo el resto a public/index.php  RewriteRule ^(.*)$ public/index.php [L,QSA]
📝 NOTENo necesitas cambiar nada más en el .htaccess. Las reglas de seguridad (CSP, HSTS, bloqueos) funcionan igual en cualquier entorno.

FASE 4: Configurar la Base de Datos del CMS

4.1 Actualizar la tabla configuracion

Ir a phpMyAdmin y ejecutar estas queries SQL:

-- Cambiar el título del sitio
UPDATE configuracion SET valor = 'HTVPERU' WHERE clave = 'site_title';

-- Verificar que la URL del sitio esté correcta
UPDATE configuracion SET valor = 'https://htvperu.com.pe' WHERE clave = 'site_url';

4.2 Crear la tabla cola_vistas (si no existe)

CREATE TABLE IF NOT EXISTS cola_vistas (
    id INT AUTO_INCREMENT PRIMARY KEY,
    noticia_id INT NULL DEFAULT NULL,
    noticia_slug VARCHAR(255) NULL DEFAULT NULL,
    ip_address VARCHAR(45) NULL DEFAULT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_noticia_id (noticia_id),
    INDEX idx_noticia_slug (noticia_slug)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

FASE 5: Configurar los Cron Jobs en cPanel

⚠️ IMPORTANTSin esto, las vistas no se contabilizan y las noticias programadas no se publican automáticamente.

Cron Job 1: Worker (Tareas Ligeras — Cada 1 minuto)

CampoValor
Minuto* (cada minuto)
Hora / Día / Mes / Día semana*
Comandophp /home/tucuenta/public_html/cron_worker.php >> /dev/null 2>&1

¿Qué hace? Publica noticias programadas, vuelca la cola de vistas, limpia rate-limits antiguos.

Cron Job 2: Backup (Tareas Pesadas — 1 vez al día a las 3 AM)

CampoValor
Minuto0
Hora3
Día / Mes / Día semana*
Comandophp /home/tucuenta/public_html/cron_backup.php >> /dev/null 2>&1

¿Qué hace? Purga papelera (+15 días), crea backup ZIP, limpia backups antiguos.

💡 TIP¿Cómo encontrar la ruta absoluta? En cPanel → Terminal ejecuta: echo $HOME. Tu public_html estará en /home/tucuenta/public_html/.

FASE 7: Configurar SSL (HTTPS)

  1. Ir a cPanel → SSL/TLS o cPanel → Let's Encrypt
  2. Generar certificado SSL gratuito para htvperu.com.pe y www.htvperu.com.pe
  3. Instalar el certificado

Tu .htaccess y conexion.php ya tienen reglas de redirección HTTPS integradas. Solo necesitas que el certificado esté activo. El HSTS también ya está configurado.

FASE 8: Configurar Cloudflare (CDN + Protección DDoS)

8.1 Configuración DNS

  1. Crear cuenta en Cloudflare
  2. Agregar tu dominio htvperu.com.pe
  3. Cambiar los Nameservers en tu registrador de dominio
  4. Verificar que los registros DNS apunten a la IP de tu hosting

8.2 Reglas de Caché (Page Rules)

  • SSL/TLS Mode: Full (Strict)
  • Always Use HTTPS: ON
  • Automatic HTTPS Rewrites: ON
  • Minimum TLS Version: 1.2
